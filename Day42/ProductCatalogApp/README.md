# ProductCatalogApp

Angular case study project for the Fake Store API.

## Features
- Fetch products from `https://fakestoreapi.com/products`
- Display products in a responsive grid
- Search and reset
- Select a product to see details
- Show product image, price, category, and rating
- Demonstrates:
  - Components
  - Services
  - HttpClient
  - Dependency Injection
  - `*ngFor`
  - `[(ngModel)]`
  - `(click)`
  - `@Input()`
  - `[src]`

## Run locally

1. Install Node.js 18+.
2. In the project folder run:

```bash
npm install
npm start
```

3. Open `http://localhost:4200`

## Notes
If you are using an older Angular CLI version, you may need to adjust package versions to match your local environment.
