# Online Book Store Management System

An Angular 17 application built per the project brief.

## Prerequisites
- Node.js 18+
- Angular CLI: `npm install -g @angular/cli`

## Setup
```bash
npm install
ng serve
```

Open http://localhost:4200

## Build
```bash
ng build
```

## Features
- Responsive navigation with live cart count
- Home page with category cards
- 7 category pages (Best Sellers, Fiction, Non-Fiction, Technology, Self-Help, Children's Books, Academic)
- Shopping cart with quantity controls, remove, and clear
- Reactive checkout form with validation
- Cart persistence via Local Storage
